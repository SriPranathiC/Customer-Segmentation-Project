# Customer-Segmentation-Project
Built a customer segmentation model across 525K transactions to identify behavioral patterns for targeted retention. Cleaned transaction data in Pandas, and engineered RFM features, applied Yeo-Johnson normalization and tuned K-Means using Elbow-Silhouette analysis. Identified 4 target segments achieving 0.49 Silhouette, 0.76 Davies-Bouldin scores.
